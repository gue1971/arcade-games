# アーケードゲームリスト

日本語タイトルからROM名を探せる、1,712本のアーケードゲーム一覧です。

## 表示

`index.html` をブラウザで開いてください。製造年・製造元・ジャンル・操作方法による絞り込み、キーワード検索、列の並べ替えに対応しています。広い画面ではジャンルとコントローラを独立した列に表示します。スマートフォンでは一覧性を優先してこの2列と名前・メモ列を隠しますが、ジャンル・操作方法のフィルターは利用できます。ジャンルは `history.dat` とゲーム情報に加え、未分類だった作品はコミュニティ管理の CatVer.ini の分類を大分類へまとめて補いました。操作方法はMAMEの入力情報をもとにし、情報がないものは「不明」としています。

ゲーム名から取り除いた地域・バージョン・海外名などは「メモ」列に移しています。

## 収録データについて

既存リストに加え、提供された MAME Plus! 日本語版 `history.dat`（AGDB / MAME E2J / 2ちゃんねる利用者による更新、Ver. 0.136u4）から日本語タイトルを取り込みました。ROM名と動作状態は MAME 0.221 の一覧で確認し、年はMAME情報、製造元は `history.dat` の開発元表記を優先しています。MAME 0.221 で `good` または `imperfect` とされる項目を対象にし、麻雀、花札、賭博、分類資料で成人向けとされる作品、ライトガン必須、DDRなど専用ダンスパネル前提、専用送信機型コントローラー必須、潜望鏡操作が前提のシーウルフ系、パンチアウト系の2画面専用タイトルを除外しています。日本版ROMが確認できた海外版エントリーは日本版ROM名へ置き換え、同じ日本版ROMに重複する項目は統合しました。日本版ROMが特定できない項目は、国内販売が確実でない可能性を残したまま候補として保持しています。パドル・トラックボール・マウス・アナログ操作や通常のスティック操作で楽しめる作品は残し、アウトランやハングオンのような運転ゲームも除外していません。タイトル・ROM名の対応や成人向け判定には、資料の古さや分類者の見解による例外が残る可能性があります。
