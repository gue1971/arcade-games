# アーケードゲームリスト

日本語タイトルからROM名を探せる、1,748本のアーケードゲーム一覧です。

## 表示

`index.html` をブラウザで開いてください。製造年・製造元・ジャンル・操作方法による絞り込み、キーワード検索、列の並べ替えに対応しています。広い画面ではジャンルとコントローラを独立した列に表示します。スマートフォンでは一覧性を優先してこの2列と名前・メモ列を隠しますが、ジャンル・操作方法のフィルターは利用できます。ジャンルは `history.dat` とゲーム情報に加え、未分類だった作品はコミュニティ管理の CatVer.ini の分類を大分類へまとめて補いました。操作方法はMAMEの入力情報をもとにし、情報がないものは「不明」としています。

ゲーム名から取り除いた地域・バージョン・海外名などは「メモ」列に移しています。

## 収録データについて

既存リストに加え、提供された MAME Plus! 日本語版 `history.dat`（AGDB / MAME E2J / 2ちゃんねる利用者による更新、Ver. 0.136u4）から日本語タイトルを取り込みました。ROM名と動作状態は MAME 0.221 の一覧で確認し、年はMAME情報、製造元は `history.dat` の開発元表記を優先しています。MAME 0.221 で `good` または `imperfect` とされる項目を対象にし、`preliminary`、麻雀、明らかな成人向け、家庭用移植、ライトガン必須のゲーム、DDRなど専用ダンスパネルが前提のゲーム、メダル・スロット・ギャンブル系（`history.dat` のジャンルやMAMEの設定表記も確認）、花札機など賭博用操作盤、専用送信機型コントローラーが必須のゲーム、潜望鏡操作が前提のシーウルフ系、パンチアウト系の2画面専用タイトル、地域表記が日本以外のROMは除外しています。パドル・トラックボール・マウス・アナログ操作や、通常のスティック操作で遊べる作品は残し、アウトランやハングオンのような運転ゲームも除外対象にはしません。地域が明記されていないROMは候補として残しています。タイトルとROM名の対応には、元データの古さや表記差による例外が残る可能性があります。
